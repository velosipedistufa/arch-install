# Mihomo program config

Program-level settings for **mihomo** (core) and **mihomo-tui** (dashboard).  
**Proxy/VLESS profiles are not included** — add those under `proxies:` in your live `~/.config/mihomo/config.yaml`.

## Layout

| Path | Purpose |
|------|---------|
| `config.yaml` | Core: ports, TUN (incl. `inet6-address`), DNS `redir-host`, sniffer. No proxy nodes. |

| `mihomo-tui/` | TUI API URL / UI defaults |
| `systemd/` | User unit + drop-ins (system proxy, TUN IPv6 ensure) |
| `bin/` | `mihomo-ensure-tun` (YAML+API pin), `mihomo-system-proxy`, `mihomo-tui-launch` |
| `pacman/mihomo-setcap.hook` | Restores CAP_NET_ADMIN after `mihomo`/`mihomo-bin` upgrades |
| `desktop/` | Fuzzel/desktop entry |

## Why `inet6-address`?

Without `tun.inet6-address`, TUN often redirects **IPv4 only** and IPv6 goes direct.  
`mihomo-tui` / `PATCH /configs` can omit that field; **Restart** then drops IPv6 tunneling until YAML is re-applied.  
`bin/mihomo-ensure-tun` + systemd `ExecStartPre`/`ExecStartPost --apply` re-assert enable + addresses on every start.
A pacman hook restores `setcap` after package upgrades (file capabilities are otherwise lost and TUN snaps back to false).

## Install onto a machine

```sh
REPO=…/arch-install   # this repo
install -d ~/.config/mihomo ~/.config/mihomo-tui \
  ~/.config/systemd/user/mihomo.service.d ~/.local/bin ~/.local/share/applications

install -m 644 "$REPO/mihomo/config.yaml" ~/.config/mihomo/config.yaml
# then merge your proxy profiles into ~/.config/mihomo/config.yaml

cp -a "$REPO/mihomo/mihomo-tui/." ~/.config/mihomo-tui/
install -m 644 "$REPO/mihomo/systemd/mihomo.service" ~/.config/systemd/user/mihomo.service
install -m 644 "$REPO/mihomo/systemd/system-proxy.conf" ~/.config/systemd/user/mihomo.service.d/
install -m 644 "$REPO/mihomo/systemd/tun-ipv6.conf" ~/.config/systemd/user/mihomo.service.d/
install -m 755 "$REPO/mihomo/bin/"* ~/.local/bin/
install -m 644 "$REPO/mihomo/desktop/mihomo-tui.desktop" ~/.local/share/applications/

# Caps for TUN as user (also installed as /etc/pacman.d/hooks/mihomo-setcap.hook):
#   sudo setcap 'cap_net_admin,cap_net_raw,cap_net_bind_service=+ep' /usr/bin/mihomo

systemctl --user daemon-reload
systemctl --user enable --now mihomo.service
```

`tun.inet4-address` `198.18.0.1/30` and `tun.inet6-address` `fdfe:dcba:9876::1/126` are **on-link dummy addresses inside the TUN** (Clash Meta defaults / documentation ULA). They are not public IPs.

`mihomo-tui/config.runtime.yaml` is UI state regenerated by the TUI — not stored here.

Packages: `mihomo` / `mihomo-bin`, `mihomo-tui` / `mihomo-tui-git` (see root `setup.sh`).
